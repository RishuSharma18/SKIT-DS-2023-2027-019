# Initial Research & Project Notes

**Date:** 13 August 2026  
**Project:** Smart CCTV Parking & Vehicle Safety System

## Key Objectives
- Real-time vehicle detection and tracking using computer vision models.
- Automatic License Plate Recognition (ALPR / ANPR) for entry/exit logging.
- Smart parking slot allocation and occupancy management.
- Real-time incident detection: wrong-way parking, unauthorized vehicles, and collisions.
- Operator dashboard for live alerts, analytics, and security notifications.
