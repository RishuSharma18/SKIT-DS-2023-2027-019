# Overstay Visual Indicator & Warning Modal Specification

Design specifications for highlighting vehicles exceeding allowed parking durations.

## Visual States
- Normal Session: Neutral slate border.
- Approaching Limit (> 75% duration): Yellow alert border with warning icon.
- Overstay Exceeded (> 240 mins): Flashing red badge with live overstay duration counter.
- Detail Modal: Shows vehicle plate, entry timestamp, and direct 'Notify Security' action button.
