# Design System Tokens and Color Schemes

Design token definitions for the Smart CCTV Parking Dashboard.

## Color Palette (Dark Mode First)
- **Background**: `#0f172a` (Slate 900)
- **Card Background**: `#1e293b` (Slate 800)
- **Border**: `#334155` (Slate 700)
- **Accent Primary**: `#3b82f6` (Blue 500)

## Slot State Color Tokens
- `AVAILABLE`: `#10b981` (Emerald 500)
- `OCCUPIED`: `#ef4444` (Red 500)
- `RESERVED`: `#f59e0b` (Amber 500)
- `VIOLATION`: `#8b5cf6` (Purple 500)
- `OVERSTAY`: `#f97316` (Orange 500)

## Typography Scales
- Heading 1: `font-bold text-2xl tracking-tight`
- Subheading: `font-semibold text-lg text-slate-200`
- Body Text: `text-sm text-slate-400`
- Badge: `text-xs font-medium px-2.5 py-0.5 rounded-full`
