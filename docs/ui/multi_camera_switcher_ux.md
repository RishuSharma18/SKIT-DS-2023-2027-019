# Multi-Camera Video Feed Switcher UX

User interface design for switching between camera video streams.

- Grid View: Quad-split view displaying Cam-1 (Gate), Cam-2 (Zone A), Cam-3 (Zone B), Cam-4 (Exit).
- Fullscreen Zoom: Double-click any camera stream to expand to full canvas view.
- Real-time overlay: Slot polygon boundaries rendered directly on top of video frames.
