# Navigation & Sidebar Specification

Sidebar navigation specifications and keyboard navigation shortcuts.

## Menu Items
1. **Overview Dashboard** (`/`): Real-time lot visualization, slot matrix, open alerts.
2. **Session History** (`/sessions`): Searchable archive with export to CSV.
3. **Security Watchlist** (`/watchlist`): Active plate flags, reason codes, operator registry.
4. **Camera Feeds** (`/cameras`): Multi-camera stream selection and zone calibration polygons.

## Keyboard Shortcuts
- `Space`: Acknowledge topmost active alert.
- `F`: Focus search input.
- `R`: Refresh live slot state.
- `Esc`: Close open modal.
