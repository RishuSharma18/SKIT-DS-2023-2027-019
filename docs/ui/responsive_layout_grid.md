# Responsive Viewport Breakpoint Specifications

Viewport breakdown for multi-monitor operations and mobile responsiveness.

- **Mobile View (< 768px)**: Single column stacked layout. Collapsible alerts drawer.
- **Tablet (768px - 1280px)**: Two column layout. Slots take 65% width, telemetry 35%.
- **Desktop (1280px - 1920px)**: 3-column dashboard with full live feed and analytics.
- **Ultra-Wide (4K / 2560px+)**: Grid splits into 4 columns with multi-camera live video.
