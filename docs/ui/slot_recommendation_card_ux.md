# Smart Slot Recommendation Card UX

User interface design for recommended parking spot navigation banner.

## Display Elements
- Large recommended slot badge (e.g., `Slot A-03 (ZONE-A)`).
- Matched category pill (`COMPACT_CAR`).
- Turn-by-turn guidance prompt ("Proceed to Row A, 3rd bay on the right").
- Reservation expiry countdown timer (300s TTL).
