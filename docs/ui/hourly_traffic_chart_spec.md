# Hourly Traffic Bar Chart Specification

Interactive SVG/Canvas bar chart specifications for 24-hour occupancy trends.

## Chart Configuration
- X-Axis: 24 hourly intervals (`00:00` to `23:00`).
- Y-Axis: Inflow count with dynamic linear scaling.
- Active Hour Highlight: Distinct neon blue accent for current operating hour.
- Tooltip: Hover card detailing total entries and peak category breakdown.
